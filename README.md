## Cómo se aprueba la cursada?

1. Aprobar la entrega de cursada, que es un TP que abarca las prácticas 1 y 2.
2. Aprobar el primer parcial (Matemática Discreta y Álgebra).
3. Aprobar el segundo parcial (Álgebra Lineal).

Cada uno de estos 3 tiene 1 recuperatorio.

## Cómo se aprueba la promoción?

Hay 2 opciones, mutuamente excluyentes:

1. Exámen teórico multiple choice.
2. Trabajo final integrador que se defiende de forma oral (no lo pienso hacer).
